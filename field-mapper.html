How shoot and run works

Shoot lines stop when a structure blocks the lane. Drag on the map (or from the player) to draw the run route; the player follows it over the time above. Stand still lets a player shoot without setting a run location. No shoot lets a player just run. Shoot over draws the line straight through structures.
